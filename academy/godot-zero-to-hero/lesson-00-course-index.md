# Godot Zero to Hero — Lesson 00: Course Index

## Purpose

This lesson captures the first external learning source for The Forsaken Saga development journey.

The goal is not to copy the course. The goal is to build a learning bridge between the course, Phil's notes, the game prototype, and the public development journal.

## Learning Source

Course: freeCodeCamp Godot beginner game development crash course.

Source Type: YouTube tutorial.

Status: Active learning source.

Usage: Orientation before Sprint 01.

## Learning Objective

Understand the Godot workshop before building The Forsaken Saga.

This means learning the editor, scenes, nodes, scripts, input, simple movement, collision, UI, signals, and export workflow.

## Forsaken Saga Mapping

Scenes become rooms, chambers, roads, taverns, battlefields, and dungeons.

Nodes become player objects, NPCs, UI panels, dice displays, journal windows, trigger zones, doors, and encounter markers.

Scripts become behaviour: movement, dialogue, state changes, dice rolls, surge meter updates, scene transitions, and journal entries.

UI becomes the old-school CRPG interface: viewport, command log, dialogue panel, party sheet, surge meter, inventory, and lore window.

Signals become game events: choice selected, NPC spoken to, dice rolled, state changed, clue discovered, journal updated.

## Lesson 00 Exit Criteria

Phil has watched the course enough to understand the shape of Godot.

Phil can explain what a scene is.

Phil can explain what a node is.

Phil understands that scripts attach behaviour to nodes.

Phil understands why the first prototype should be small.

Phil has recorded notes in the learning journal.

## Sprint Gate

Sprint 01 does not start until Lesson 00 notes exist.
