Share Settings

GitHub token for Gist sharing. Private Local Mode only.

Use a GitHub Personal Access Token with only the gist scope. The token is stored in this browser only and used only for GitHub Gist sharing.

⚠ Security note: this token is stored unencrypted in this browser's localStorage. Anyone with access to this device or browser profile can read it. Use a gist-scoped token only (no repo, no admin, no other scopes), and clear it when you are finished. Never paste a broadly-scoped token here.
