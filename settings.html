Settings

Global workspace controls for Public Demo Mode, Private Local Mode, and Hide Values.

Privacy Mode

Applies to Crypto Workspace, Stocks Workspace, Journal, and Reports

Public Demo Mode uses demo-only data and is safe to share.

Private Local Mode stores records in this browser only. It does not sync across users or devices.

Hide Values masks holdings, positions, entry prices, trade amounts, unrealised P/L, and report values across both workspaces.

Share Settings

GitHub PAT for Gist sharing — Private Local Mode only

To share trade snapshots via GitHub Gist, provide a GitHub Personal Access Token with gist scope. The token is stored in this browser only and never committed or transmitted except to api.github.com.

Create a token at github.com → Settings → Developer settings → Personal access tokens. Select only the gist scope.
