# Magister Automatorum

## Working Position

Magister Automatorum is a founder AI control plane for capital-constrained builders.

It helps a solo founder or small team route work across AI tools, repositories, deployment platforms, publishing channels, and operating memory without losing control of cost, context, or execution quality.

This is not an autonomy-first AI platform.

It is a command-and-control operating model where the founder remains accountable and AI tools become specialised execution shells.

## Core Model

```text
Founder judgement first.
AI execution shells second.
GitHub as durable source of truth.
Obsidian as operating memory.
Cloudflare and Vercel as deployment fabric.
Revenue channels connected back into the operating loop.
```

## Current Stack

- ChatGPT for planning, FinOps, lightweight synthesis, and operating logic
- Codex for scoped implementation and repo changes
- Claude for long-form writing and heavy multi-repo work
- GitHub for repos, issues, and deployment source
- Obsidian for continuity and control-plane memory
- Cloudflare for edge governance and analytics
- GitHub Pages / Cloudflare Pages / Vercel for publishing and deployment
- HubSpot / LinkedIn / Clay / Medium for revenue development and public narrative

## Product Direction

The first product is not SaaS.
