User Guide

ZenCloud is a manual crypto swing-trading operating system: scan, analyse, plan, execute externally, update holdings, journal, and review.

If the idea did not start in ZenCloud, do not execute it in CoinSpot. ZenCloud decides. CoinSpot executes. ZenCloud records and reviews.

What ZenCloud Is

Decision, planning, journaling, and review

ZenCloud turns live market data, manual holdings, and journal records into a compact swing-trading workspace. It is not an exchange, not an auto-trader, and not a prediction engine.

Core Operating Rule

Keep execution separate

Use ZenCloud to decide, plan, record, and review. Use CoinSpot only for the external execution handoff after an asset has been analysed and a trade plan has been confirmed.

Daily Trading Workflow

Run the same sequence each session

  1. Scan the Opportunity Queue.
  2. Analyse one asset.
  3. Create or confirm a trade plan.
  4. Execute in CoinSpot only when ready.
  5. Update manual holdings.
  6. Journal the trade.
  7. Review reports, logs, and alerts.

Opportunity Queue

Primary scan surface

Start on Dashboard. The Opportunity Queue ranks assets from the scoring layer and gives the fastest answer to what currently matters.

Best Swing Mover

One short-to-medium-term candidate

This box highlights one liquid, non-high-risk candidate when the current state supports further analysis. It never opens CoinSpot directly.

Asset Analysis

Inspect before acting

Analyse isolates one asset with signal state, market movement, volume context, invalidation, position sizing, and the execution handoff gate.

Trade Plan

Plan before handoff

Create a plan with the asset, signal state, reason, entry trigger, invalidation, review time, intended size, and notes. Saving a plan can add it to the Trade Journal.

Position Size Helper

Sizing context only

The helper estimates intended allocation, risk amount, units, and portfolio allocation after trade. It does not send orders or pre-fill CoinSpot.

CoinSpot Execution Handoff

External execution only

CoinSpot is only for placing the actual trade, checking real account balance if needed, and confirming completed transactions. ZenCloud never creates guessed CoinSpot links.

Manage Holdings

Manual local portfolio tracking

Use Manage Holdings to update balances, entry price, notes, and timestamps after external trades. Holdings are stored locally in browser localStorage, so clearing storage or using another device may reset them.

Trade Journal

Manual record of planned and closed trades

Journal entries track entry, signal state, reason, invalidation, exit, result, and notes. The journal is manual and stored locally in the browser.

Highest Exit Risk

Held assets only

This box reviews current holdings against live state and flags the held asset most worth reviewing. It does not evaluate assets you do not hold.

Reports

Review from manual records

Reports summarise daily activity, weekly performance, closed trade reviews, current positions, and behaviour patterns using only local Trade Journal and Holdings data.

Market Logs

System telemetry

Market Logs show timestamped observations from the decision pipeline. Use them to verify what the system observed, not as a second execution surface.

Alerts

Threshold events

Alerts surface Breakout, Watch, Sell Risk, and Volume Spike events. Treat them as prompts to return to Dashboard and analyse one asset.

Fallback Snapshot

When live data is unavailable

If the live API fails, the portal shows Live API unavailable - fallback snapshot. The app remains usable, clearly labelled, and safe to review until live data returns.

Safety Rules and Disclaimer

Decision support only

  • ZenCloud is for scanning opportunities, analysing assets, creating trade plans, checking position size, monitoring exit risk, updating holdings, journaling trades, and reviewing performance.
  • CoinSpot is for placing the actual trade, checking real account balance if needed, and confirming completed transactions.
  • ZenCloud does not execute trades, automate orders, or handle exchange API keys.
  • All external trade decisions remain at the user's discretion.
