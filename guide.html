User Guide

Operate ZenCloud as a lightweight decision terminal: scan, analyse, then use an external execution handoff only when ready.

What ZenCloud Is

A decision terminal, not an execution venue

ZenCloud compresses live crypto market data into ranked opportunities, telemetry, and threshold events. It is designed to reduce noise and help users follow a deliberate process before leaving the portal for external execution.

10-Step Workflow

Use this order every session

  1. Open Dashboard.
  2. Check Opportunity Queue first.
  3. Review only top-ranked assets.
  4. Click Analyse on one asset.
  5. Check signal state.
  6. Confirm 1hr and 24hr alignment.
  7. Review Portfolio and Holdings.
  8. Open CoinSpot only after analysis.
  9. Update Manage Holdings after external trades.
  10. Use Logs and Alerts for verification, not execution.

Dashboard / Opportunity Queue

Primary decision surface

Start with the Opportunity Queue. It ranks assets from the scoring layer and shows the state, score, price, 1hr movement, and 24hr movement. Treat it as the first scan surface, not as a general market explorer.

Analyse Before Execution

One asset at a time

Click Analyse before considering any external action. The analysis panel isolates one asset so you can review signal state, score context, price movement, volume, and portfolio exposure before the execution handoff appears.

Market Logs

Telemetry and traceability

Market Logs show timestamped system observations. Use them to verify what the system observed and when. Logs are read-only telemetry and should not be treated as a second decision surface.

Alerts

Threshold events only

Alerts are event-driven outputs for important threshold changes: Breakout, Watch, Sell Risk, and Volume Spike. Use alerts to notice state transitions, then return to Dashboard for analysis.

Manage Holdings

Manual local portfolio tracking

Holdings are entered manually and stored locally in your browser under localStorage. After an external trade, update Manage Holdings so Portfolio and My Holdings reflect your current balance.

Clearing browser storage, using another device, or opening a different browser profile may reset local holdings.

Fallback Snapshot

When live data is unavailable

If the live API fails, the portal shows Live API unavailable - fallback snapshot. The app should remain usable, clearly labelled, and safe to scan until live data returns.

Behavioural Rules

Keep the workflow deliberate

  • Dashboard is the primary decision surface.
  • Logs and Alerts are verification layers, not execution layers.
  • Review only a small number of ranked assets.
  • No external execution handoff before analysis.

Important Disclaimer

Decision-support only

ZenCloud is a decision-support tool only. It does not provide financial advice, execute trades, or guarantee outcomes. All trades are executed externally through CoinSpot at the user's discretion.
