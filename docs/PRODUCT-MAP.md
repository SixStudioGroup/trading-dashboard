# Product Map

## Product Positioning

SixQuant Trading Dashboard is a manual decision-support platform for crypto swing trading and structured market review. The product is not intended to become an automated trading engine or brokerage interface.

The platform should optimise disciplined decision-making, portfolio awareness, execution gating, and review.

## Core Product Areas

### Decision Terminal

The primary workflow surface.

Responsibilities:

- Opportunity Queue
- Asset Analysis
- Trade Guide
- Signal State
- Decision Validation
- Execution Unlock
- Risk Visibility

This is the centre of the platform and should always remain the highest priority product area.

### Portfolio Control

The portfolio surface exists to maintain trader awareness rather than become a tax or accounting system.

Responsibilities:

- Manual Holdings
- Live AUD Valuation
- Unrealised Gain/Loss
- Position Weighting
- Portfolio Exposure
- Manual Trade Recording

### Watch and Alerting

This module supports trader awareness and prioritisation.

Responsibilities:

- Watch Queue
- Market Attention
- Signal Changes
- Alert States
- Fallback Visibility
- Feed Health

### Journal and Review

This module converts trading into a repeatable learning process.

Responsibilities:

- Trade Journal
- Session Notes
- Signal History
- Performance Summary
- Review History
- Mistake Tracking

### Product Trust Layer

This layer exists to establish confidence in the platform.

Responsibilities:

- Live/Fallback Status
- Data Source Visibility
- Timestamp Visibility
- Retry State
- Known Limitations
- Manual Execution Boundary

## Release Direction

### Release 0.x

Prototype and workflow validation.

Focus:

- UI structure
- Opportunity scanning
- Manual holdings
- Live feed handling
- Decision gating proof

### Release 1.0

Structured manual trading terminal.

Focus:

- Refined workflow hierarchy
- Reduced UI clutter
- Improved analysis flow
- Stronger invalidation model
- Stable review loop
- Documentation maturity

### Release 1.1

Trader review and reporting.

Focus:

- Journal improvements
- Trade tagging
- Review summaries
- Performance trends
- Decision replay

### Release 1.2

Signal intelligence and prioritisation.

Focus:

- Smarter alerts
- Better filtering
- Session scoring
- Risk prioritisation

### Release 2.0

Optional integration phase.

Potential scope:

- Optional exchange integrations
- Portfolio import
- Export/reporting
- Multi-device sync

Exchange execution should remain disabled unless the product matures into a governed trading platform with explicit execution controls.
