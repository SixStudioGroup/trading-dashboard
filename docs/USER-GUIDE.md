# User Guide

## Product Workflow

The dashboard is designed around a structured manual trading workflow.

The intended sequence is:

1. Scan opportunities.
2. Analyse a selected asset.
3. Confirm the decision.
4. Execute externally.
5. Record the outcome.
6. Review the session.

## Opportunity Queue

The Opportunity Queue is the primary entry point.

Use it to:

- Review ranked opportunities.
- Compare signal strength.
- Prioritise attention.

## Asset Analysis

Selecting an opportunity should unlock deeper analysis.

Review:

- Signal conditions
- Market context
- Risk state
- Trade confidence

## Execution Boundary

The dashboard does not place trades.

Trades should be executed externally through CoinSpot or another exchange.

## Manual Holdings

Holdings are managed manually.

Use the holdings controls to:

- Add positions
- Remove positions
- Update quantities
- Review portfolio value

## Fallback State

If live feeds are unavailable, the dashboard may enter fallback mode.

Fallback mode exists to maintain continuity while making the data state visible to the user.

## Review

Use the review surfaces to evaluate:

- Previous decisions
- Signal quality
- Session outcomes
- Portfolio movement
