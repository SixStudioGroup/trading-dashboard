# Information Classification

Archivum uses four information classes.

| Class | Meaning | Typical handling |
|---|---|---|
| Public | Approved for public release | May appear in public framework or published outputs |
| Internal | Routine working information | Private repo, normal engagement access |
| Confidential | Commercially or operationally sensitive | Restricted collaborator list and careful export handling |
| Restricted | Highest sensitivity accepted by the engagement | Explicit approval, named access, additional controls and review |

The artefact owner assigns classification when the artefact is created and reviews it before handover.

Classification should reflect the content, not the folder name. A public template can produce a confidential completed artefact once client information is inserted.

Restricted storage is not automatic. The engagement owner must confirm that GitHub is an approved location and that contractual and client requirements are met before restricted material is committed.

When uncertain, classify at the higher level temporarily and request a decision.

Exports inherit the classification of their source artefacts unless a documented review changes it.
