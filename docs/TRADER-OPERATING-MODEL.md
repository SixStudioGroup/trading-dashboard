# Trader Operating Model

## Core Principle

ZenCloud decides.
CoinSpot executes.
ZenCloud records and reviews.

The dashboard is a manual decision-support environment.

## Workflow

### Scan

Review the opportunity queue and prioritise potential trades.

### Analyse

Select a single opportunity and review:

- Trade thesis
- Confirmation state
- Risk state
- Invalidation conditions

Execution should remain locked until analysis is complete.

### Decide

The trader chooses whether to:

- Execute externally
- Watch the asset
- Reject the trade
- Revisit later

### Execute

Trades are executed outside the dashboard.

### Record

The trader updates holdings, notes, and review history.

### Review

The trader reviews outcomes, signal quality, and decision consistency.

## Product Philosophy

The platform is intended to support:

- Disciplined decisions
- Repeatable workflows
- Portfolio awareness
- Structured review
- Clear execution boundaries
