# UX Review

## Current Product Assessment

The dashboard already communicates a strong product identity.

It feels closer to a trader decision terminal than a hobby portfolio tracker. The current release demonstrates:

- A structured opportunity queue.
- Controlled execution flow.
- Manual holdings awareness.
- Live versus fallback transparency.
- Signal-oriented thinking.

The product direction is valid.

## Primary UX Weakness

The interface currently exposes too many simultaneous surfaces.

The trader is asked to process:

- Opportunities
- Portfolio state
- Market attention
- Alerts
- Holdings
- Signals
- Review information
- Performance information

within the same active frame.

This creates cognitive overload.

## UX Direction

The platform should prioritise a calm decision environment.

The dashboard must answer one question at a time:

What should the trader focus on right now?

The product hierarchy should become:

1. Opportunity.
2. Analysis.
3. Decision.
4. Execution.
5. Review.

Everything else should support this loop.

## Strong Existing Decisions

The following decisions should remain:

- Execution gating.
- Manual execution boundary.
- CoinSpot external execution.
- Live/fallback transparency.
- Opportunity-first workflow.
- Manual holdings.

## Recommended Improvements

Release 1.0 should:

- Reduce simultaneous panels.
- Increase whitespace and focus.
- Make the selected opportunity dominant.
- Push secondary market context lower.
- Improve invalidation visibility.
- Reduce visual noise from low-priority metrics.

## Trader Perspective

A trader should feel:

- Calm.
- Directed.
- In control.
- Deliberate.

The current product already leans toward discipline rather than hype. That should remain a defining characteristic of the platform.
